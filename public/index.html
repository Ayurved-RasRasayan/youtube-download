⚙️ Setup Required

To enable actual video downloading, you need to start the backend server:

  1. Install yt-dlp (YouTube downloader):
    pip install yt-dlp
    Or for macOS: brew install yt-dlp
  2. Navigate to the project folder:
    cd /home/z/my-project/youtube-downloader/server
  3. Install Node.js dependencies:
    npm install
  4. Start the server:
    node server.js
  5. Open this page at: http://localhost:3000
