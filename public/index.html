⚙️ Setup Required

To enable actual video downloading, you need to start the backend server:

  1. Install yt-dlp (YouTube downloader):
    pip install yt-dlp
    Or for macOS: brew install yt-dlp
  2. Navigate to the project folder:
    cd /home/z/my-project/youtube-downloader/server
  3. Install Node.js dependencies:
    npm install
  4. Start the server:
    node server.js
  5. Open this page at: http://localhost:3000

💡 How to get your Liked Videos URL:
Option 1 - Full Playlist URL:
1. Open YouTube → Click Library → Liked videos
2. Copy the FULL URL (looks like: ...playlist?list=LLXXXXX)

Option 2 - Any Liked Video Link (NEW!):
1. Open any video you've liked on YouTube
2. Copy its URL (looks like: ...watch?v=XXX&list=LL...)
3. Paste it above - we'll detect it's from your Liked Videos!
